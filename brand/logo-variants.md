# 住凯AI视频 — logo 变体规格

第 1 轮，12 个变体，覆盖 5 种 mark 结构。这是**决策材料**，不是最终标志：
选定方向后再做生产级精修（字距、光学校正、色板定稿、应用库）。

渲染图：`variantSheet.png`（含各变体的 64 / 32 / 16px 与反白实测）
可编辑源：`variantSheet.html`

---

## 输入（brief）

| 项 | 内容 |
| --- | --- |
| 品牌名 | 住凯AI视频（品类描述词「AI视频」随名同行） |
| 类别 | AI 视频创作工具，本地优先 |
| 受众 | 个人创作者与小型团队；**决定场景是应用图标与浏览器标签** |
| 基调 | 克制 → 清晰 → 有结构；偏现代、偏专业 |
| 应用场景 | 网页页眉、应用图标 28px、favicon 16–32px、深色界面、单色印刷、刺绣、动效 |
| 硬约束 | 必须能单色、能反白、16px 可辨；**绿色系保留**（`#2E9E6B`） |
| 现状 | 沿用上游的 Toonflow 图标，本轮的 08 号是已选定的方向 |

### 需要的结构分层（这是本轮的核心判断）

16px 下**任何组合（lockup）都会失败**。所以必须从一开始就规划回退层级：

```
主用    05 横排组合       网页页眉、文档抬头、邮件签名
方形    06 竖排组合       社交头像、名片、包装正面
小尺寸  08 或 09 纯符号   favicon、应用图标、刺绣
```

## 变体

### 01 · 几何无衬线字标

- **结构** 字标（wordmark only）
- **字体** 几何无衬线，500 字重，字距 +0.01em
- **色值** `#F2F4F2`（深底）/ `#0E1110`（浅底）；单色黑 `#000`、单色白 `#FFF`
- **应用** 大尺寸尚可；**16px 必然失败**，需回退符号
- **信号** 现代、中性，AI 品类的安全答案
- **拒绝** 个性、记忆点

### 02 · 人文无衬线字标

- **结构** 字标
- **字体** 人文无衬线，600 字重，字距 −0.015em
- **色值** 同上
- **应用** 同 01；16px 失败
- **信号** 专业但温和，贴创作者工具
- **拒绝** 冷硬科技感
- **说明** 与 01 的差别在小尺寸下不可辨 —— 二者**不应同时进入终选**

### 03 · 过渡衬线字标

- **结构** 字标
- **字体** 过渡衬线，600 字重，字距 +0.01em
- **色值** 同上
- **应用** 大尺寸与印刷表现最好；16px 失败
- **信号** 编辑感、严肃
- **拒绝** 品类惯例 —— 视频工具极少用衬线，**这是可用的差异化位**
- **风险** 与「AI 视频」的即时联想有距离，可能被读成出版社或法律品牌

### 04 · 定制字重对比字标

- **结构** 字标
- **字体** 同一字体族，靠字重对比分层：**「住凯」700 / 「AI视频」400**
- **定制** 无需绘制字形，用字重与字距建立节奏，成本最低但有效
- **色值** 「住凯」用品牌绿 `#2E9E6B`（可选），其余中性；单色版全白
- **应用** 大尺寸好；16px 失败
- **信号** 把品牌名与品类词分开，无符号也有节奏
- **拒绝** 平均用力的字标
- **评价** 四个字标里**最有余地**的一个：不依赖符号，也不靠字体个性

### 05 · 横排组合（符号在左）

- **结构** 组合（lockup）
- **字体** 人文无衬线，600 字重
- **符号** 抽象几何：方形画框，右下角整段缺席，框内负空间切出视频三角
- **构造** 外沿 192、边宽 30、缺口 30 见方、三角顶角 59.9°（`2·atan(45/78)`）
- **色值** 符号与字标同色；主色 `#2E9E6B`，深底用 `#F2F4F2`
- **应用** 网页页眉、文档抬头、邮件签名 —— 这些位置宽度充足，横排最省空间
- **小尺寸** 16px 回退到 08
- **信号** 画布（有边界的编辑区）+ 播放（视频），右下开放 = 无限画布
- **拒绝** 通用 AI 图形（节点、Sparkle、原子）
- **评价** 主用形态的默认选择

### 06 · 竖排组合（符号在上）

- **结构** 组合（stacked）
- **字体** 人文无衬线，600 字重
- **符号** 同 05
- **色值** 同 05
- **应用** 社交头像、名片、包装正面、任何方形位
- **小尺寸** 16px 回退到 08
- **信号** 与 05 一致，只是适配方形
- **说明** 05 与 06 是**同一方向的两种排布**，不是竞争关系，应一起采纳

### 07 · 框内嵌字（方形）

- **结构** 组合
- **字体** 人文无衬线，600 字重
- **符号** 把画框放大成容器，「住凯」二字嵌在其中
- **色值** 同 05
- **应用** 方形场景、贴纸、标签
- **信号** 把「画布」直接做成外框，标志本体即产品
- **拒绝** 分隔式的符号 + 字标
- **风险** 为容纳文字，右下缺口必须闭合 —— **牺牲了 05 的"开放画布"语义**。语义上不如 05，
      但如果重视"标志即产品"，这是唯一把字嵌进画布的方案

### 08 · 框与三角（已选定方向）

- **结构** 纯符号
- **符号** 几何简化（无具体指涉）
- **构造** 见 05
- **色值** 主色 `#2E9E6B`；单色黑/白成立
- **应用** **favicon、应用图标、刺绣**；这是小尺寸主用
- **信号** 画布 + 播放
- **风险** **播放三角是本品类最被用尽的符号**（库中 `youtube`、`leankit`、`google-play` 都用了）
- **实测** 16px 下仍可辨、反白成立、无渐变依赖 —— 见 `variantSheet.png` 右下角测试行

### 09 · 框与三角（蓝本加厚）

- **结构** 纯符号
- **符号** 同 08，但边宽 30 → **36**，外沿 192 → 200
- **色值** 同 08
- **应用** 同 08；**刺绣与低分辨率更适合**
- **信号** 同 08，但更重、更稳
- **比较** 与 08 **二选一**，取决于实机 16px 与刺绣表现。加厚在极小尺寸下更抗糊，
      代价是大尺寸下略显笨重

### 10 · 住字标（字母形符号）

- **结构** 字母形符号（letterform-as-symbol）
- **符号** 把「住」压成纯几何块面：左「亻」为竖 + 45° 短撇；右「主」为点 · 两横 · 竖
- **构造** 笔画厚 24；外沿 48..208；直角，与画布硬边一致
- **色值** 单色即可；建议主色或纯黑
- **应用** favicon、应用图标、单色印刷、刺绣均可
- **信号** 与中文名直接绑定，**别人无法复制**
- **风险** 是「近似」而非规范字形（「主」的点与竖合并），**可能被挑字**
- **评价** 12 个变体里**最独占**的一个；但它是品牌字标而非功能图形，看不出"做视频"

### 11 · 凯 K 字组

- **结构** 字组（monogram）
- **符号** 取「凯」的拼音首字母 K，直角化：竖笔 + 两条斜臂
- **构造** 竖 pen 32；斜臂由直角三角构成，与画布的硬边语言一致
- **色值** 单色
- **应用** 方形场景、小尺寸
- **信号** 几何 K，与画布语言一致
- **风险** 单独一个 K 与品牌关联**弱** —— 不熟悉的人不会想到「凯」

### 12 · 住字组（方框内嵌）

- **结构** 字组
- **符号** 「住」放进方框，字与画布合一
- **构造** 框 184 见方、描边 18；内部笔画厚 18
- **色值** 单色
- **应用** 方形场景
- **信号** 字与画布合一，是 10 与 08 的融合
- **风险** 笔画细到 18，**16px 下很可能糊**

## 应用场景测试结果

只列**实际做过**的；未做的明确标注。

| 场景 | 结果 | 说明 |
| --- | --- | --- |
| 64 / 32 / 16px | ✅ 已实测 | 08 在 16px 仍可辨；12 在 16px 偏糊（笔画 18 过细） |
| 反白（白 on 黑） | ✅ 已实测 | 08 反白后视觉重量与黑版接近，未出现明显的辐射膨胀 |
| 单色（纯黑白） | ✅ 已实测 | 全部变体不依赖颜色 |
| 16px 像素级校验 | ⚠️ 部分 | 已在渲染图中目视；未做逐像素比对脚本 |
| 刺绣（1.5 英寸，≤6 色） | ❌ **未测** | 需实机打样。预期 09 优于 08（边宽 36 更抗缩） |
| 大幅招牌 | ❌ **未测** | 矢量为纯矩形 + 三角，无近角误差，预期无问题 |
| 大面积动效 | ❌ **未测** | 建议：符号从方框"长出"、缺口处三角滑入 |
| 圆形裁切（社交头像） | ❌ **未测** | 06 为方形构图，圆形裁切会切到四角留白，预期可用 |
| CMYK / 专色 | ❌ **未做** | 主色 `#2E9E6B` 需做印刷打样 |
| 商标检索 | ❌ **未做** | **无法给出法律结论**，建议在发布前自行检索商标库并做反向图片检索 |

### 回退层级（本轮的核心产出）

```
主用     05（横排） / 06（竖排）
方形     06
极小尺寸  08 或 09（二选一）
单色印刷  08 / 09 / 10
```

## 推荐

**最稳的一组**：`05 + 06 + 08`

- 05/06 是同一方向两种排布，覆盖所有正常尺寸
- 08 承担 favicon 与应用图标
- 三者共用同一符号，视觉 DNA 一致

**如果重视独占性**：把 08 换成 **10（住字标）**。代价是失去"视频"的即时联想，
换来别人无法复制的字形。这取决于你更在意**一眼看懂**还是**一眼记住**。

**如果担心播放三角太通用**：`04 + 08` 的组合值得看 —— 04 的字标本身有节奏，
不依赖符号讲视频，符号可以更抽象。

**建议淘汰**：01 与 02（差异过小，同时出示会稀释决策）；12（16px 不可用）。
