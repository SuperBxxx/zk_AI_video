# 第 2 轮 logo 候选（全新设计，不沿用第 1 轮）

本目录是**从 brief 重新推导**的一轮，刻意不参考第 1 轮的结论。
第 1 轮的产物在 `../concepts/` 与 `../logo-variants/`，仅作对照。

---

## 一、先纠正第 1 轮的两个概念错误

不做任何取舍、只看产品本身，重新做词图后发现了前几轮的方向性问题：

| 前几轮用了 | 问题 |
| --- | --- |
| **方框**（画框） | 方框表示**有界**，而产品卖点是**无限画布** —— 语义正好相反 |
| **播放三角** | 属于**播放器**，不属于**创作工具**。且是本品类最被用尽的符号（库中 `youtube`/`leankit`/`google-play`） |

所以这一轮**同时避开方框与播放三角**，从「视频的本质」与「AI 的不可画性」重新出发：

```
视频   → 时间轴（不是播放键）、帧、像素、运动、镜头
画布   → 无限边界、节点、连线
AI     → 抽象，无可画实体 —— 硬画就成了通用 AI 图形，应回避
```

## 二、先查库，避免重复劳动

| 查询 | 结果 | 含义 |
| --- | --- | --- |
| `--subject timeline` | **0 匹配** | 时间轴方向是空的 |
| `--subject aperture` | **0 匹配** | 光圈方向是空的 |
| `--query bars` | **44 匹配** | **但光有几根竖条就是通用柱状图** |

`bars` 的高分范例都靠**第二层含义**取胜：`trello`（两根条 = 看板）、
`intercom`（竖条构成笑脸）、`flutter`（斜条构成 F 与动势）。
这条数据直接预言了下面 A、B 两个候选的失败。

## 三、三个候选与结果

### A 时间轴 — ✗ 否决

- **Idea** 一条基线 + 三根不等宽竖条；中间一根悬浮在基线之上，读作关键帧
- **构造** 基线 y166..182；竖条宽 32，x 44 / 108 / 172；中条 y100..146 悬浮
- **审计** 99/100（仅提示垂直留白不均 62 vs 74）
- **否决原因** **渲染出来读作"残缺的柱状图"**，中间悬浮那块像排版错误或漏画。
  基线不足以把它拉回"时间轴"。这正是库里那 44 个 bars 案例警告的陷阱。

### B 凯字标 — ✗ 否决

- **Idea** 把「凯」压成几何块面：左「山」三根立柱 + 底横，右「几」竖笔 + 钩
- **构造** 笔画厚 24；山的三柱高 80 / 128 / 96；几的钩用直角折线
- **审计** 99/100
- **否决原因** **读作柱状图 / 音频均衡器，完全不是「凯」**。
  根因：把「几」的钩做成直角折线，**丢掉了那一笔的性格**，
  剩下的只是"五根不等高竖条 + 一条底横"。
- **另一层结论**：**把汉字压成等宽方块，几乎必然读成图表**。
  第 1 轮的「住字标」之所以还能认，是因为它的骨架接近"亻 + 主线"，
  但那是运气，不是方法 —— 这个方法本身不可靠。

### C 取景框 — ✓ 成立，推荐

- **Idea** 四角直角 + 中心十字准星。四角只到该到的地方就停（边留缺口），
  因此读作"正在框取一个比画面更大的东西" —— **这正好是无限画布**。
  中心准星把它从"裁切标记"拉向"取景器"：一眼看出是"看"与"框"。
- **构造**
  - 四角直角：臂长 64、厚 24，各留 96 的缺口；外沿 32..224
  - 中心准星：厚 16、臂长 44，中心留出 24 半径的负空间空环
  - 整体 192 见方，四边留白 32
- **审计** **100/100，无任何问题**
- **16px 实测** **仍可辨**（能认出四角与准星）—— 这是三个候选里唯一通过的

## 四、16px 实测对比（决定性证据）

见 `round2.png`，每个候选下方有 64 / 32 / 16px 的真实尺寸：

| 候选 | 64px | 32px | 16px |
| --- | --- | --- | --- |
| A 时间轴 | 可辨 | 偏挤 | 糊，读作小图表 |
| B 凯字标 | 可辨 | 糊 | **完全糊成一团** |
| **C 取景框** | 可辨 | 可辨 | **仍可辨** ✓ |

## 五、为什么推荐 C

| 维度 | 取景框 |
| --- | --- |
| **语义** | 「取景」= 视频创作的核心动作；四角开放 = 无限画布。两个含义同向，不冲突 |
| **与旧方案的区别** | 第 1 轮是**闭合方框 + 播放三角**；这里是**开放四角 + 准星**。结构、语义都不同 |
| **小尺寸** | 唯一通过 16px 的候选 |
| **单色 / 反白** | 纯填充直角，无渐变、无描边依赖，天然成立 |
| **刺绣 / 大幅** | 全部为直角矩形，无曲线、无细部，两端都稳 |
| **可扩展** | 四角与准星可拆开用于动效（准星先出现，四角后合拢） |
| **风险** | 四角直角在软件里常见（截图、裁切工具）。**这是它最大的风险** ——
需要通过准星的比例与留白把它拉出"裁切标记"的观感。是否成功需在实机上看 |
