# 参考分析节点

把一条参考视频摊成**可核对的证据**：媒体信息、按时刻的帧图、分页帧网格、画面变化候选。

## 为什么需要它

技能文档要求「参考素材先逐帧拆解成手法清单」，但在此之前 Agent 手上没有任何读素材的手段，
那条规则一直是空的。这个节点把「取证」这一步补上。

## 输出

- **证据网格图**（IMAGE）—— 可直接连给下游预览或复用。
- 证据本体（帧清单、每页格内时刻、变化候选）通过 `analyzeReference` 的返回给 Agent，
  由 Agent 组织成解读并引用证据路径。

**证据与解读分开**：节点只产出证据；「这是什么手法、为什么有效」是解读，由 Agent 写。
`transcript` 是证据，不是导演的解读 —— 这条纪律不能混。

## 两条纪律

- **变化候选只是候选，不是「镜头」**。快速运动、闪光、整句字幕出现都会造成高分，
  必须取帧回看确认后再下结论。
- **先 probe 再分析**。HEVC(H.265) 在桌面端会「有声音没画面」，预览或送模型前先转 H.264。

## 工具

- `probeReference` —— 只读媒体信息，用来决定要不要先转码。
- `analyzeReference` —— 生成完整证据（帧、网格、变化候选）。与 Agent 工具 `media_analyze`
  共用同一份实现，保证节点与工具看到的证据完全一致。
