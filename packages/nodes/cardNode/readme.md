# 画面卡

把一张**画面卡**渲成视频。

画面卡是用浏览器逐帧渲染出来的效果片段，两种形态：

- **全屏卡**：自己就是一整屏，**替代**这一段画面（不需要 AI 视频）
- **叠加卡**：透明背景的信息层，**叠在 AI 视频上**

用**成片画幅**渲染：卡是分辨率无关的（设计画布「短边恒 270、长边按画幅比伸缩」），
竖屏视频渲竖屏卡，不会出现横屏卡拼竖屏视频。但**必须显式给目标画幅**，不要用卡的默认画幅。

## 输入 / 输出

- 输入：目标视频（只有叠加卡需要）
- 输出：渲染好的视频

## 注意

- **转场卡不能用这个节点**：它作用在两个镜头之间，不是叠在一段视频上
- 卡**自带文案**，只能调数值参数，改不了字
- 渲染要驱动无头浏览器逐帧截图，**一张卡 6~15 秒**（60~150 帧），属于慢操作
- 同一个节点重复渲染会各产出一个文件，不会覆盖
