# 反 PPT 规范（镜头方法论）

这一份是**结构性要求**，不是可选的风格建议：不满足时成片必然像「播放幻灯片」。

> **落地形态说明**：我们没有 Remotion 那样的逐帧渲染栈，画面的实际运动由节点产出
> （生成模型的运镜、FFmpeg 滤镜、以及素材本身）。所以本文件的用法是
> **写生成提示词与编排分镜时的约束**——它约束的是「这一段该怎么拍」，
> 不是「该调用哪个组件」。文档里出现的层、相机、让位等概念是**构图语言**，
> 要翻译成对生成提示词的描述（例如「相机极缓推进 1.00→1.05，全程连续」）、
> 或对 FFmpeg 的操作（例如 `zoompan` 的缓慢缩放）。

## 0. PPT 感的四个病根（自检用）

1. **没有相机层**：画面静止，元素只是在固定舞台上淡入滑入。
   每段加一条「100%→104~106% 极缓慢推」或反向极缓拉出，就能消掉一半 PPT 感。
2. **元素入场后就死了**：动画全是「入场」（到位即冻结）——这正是 PPT「进入效果」的模型。
   画面的活来自**持续运动**，由相机承担，不靠元素自己抖。
3. **段落之间硬切翻页**：内容整体瞬间替换。转场要靠**运动承接**，不是靠交叉淡入。
4. **文档版式 + 信息堆积**：标题左上、要点网格是**排版思路不是构图思路**；
   元素只进不出，讲到后面满屏静物。**一个节拍只讲一个主角，说完就让位。**

## 1. 七层镜头模型（构图词汇）

| 层 | 职责 | 典型动作 |
| --- | --- | --- |
| L1 相机 | 带观众穿过空间 | **极缓推进 / 极缓拉出**（唯一必需的运动） |
| L2 焦点 | 决定什么在光学上可读 | 虚→实入场、移焦、集体退焦只留主体 |
| L3 主体 | 唯一主角的运动与变形 | 入场、接力、变形、动态文字 |
| L4 附着效果 | 主体的材质与状态提示 | 辉光、边缘光、粒子、闪光 |
| L5 配角 | 与主体互动、强化主体 | 反向运动、光束、环、时间轴、视差层 |
| L6 环境 | 氛围 | 分段色温（静态 token，可选） |
| L7 遮罩 | 控制可见性与取景 | 描边旅行、扫描线揭示、裁剪揭示 |

**层预算**：英雄时刻 4–6 层活跃；过渡镜头 2–3 层；
**静息时刻允许只有相机一层在动**——观众在听人说话、看字幕，
画面的活只需一条几乎察觉不到的相机呼吸。

## 2. 运动做减法（正主）

只保留两件事：**相机极缓推进或拉出** + **让位**。

以下一律**不要求**，能不做就不做：主体闲置微动、环境呼吸、斜向扫光、
曝光脉冲、相机重音脉冲、x/y 摇移、旋转、模糊曲线。

- 相机**每段只有一条极缓的缩放曲线**：推 1.00→1.04~1.06，或拉 1.06→1.00。
  全程连续，末键落在段落之外。
- **不做** x/y 摇移、旋转、模糊曲线，**不加**重音脉冲与抖动。
  素材自身要动的，用运镜作用在**素材层**，不动场景相机。
- **同起同收**：相机曲线、实拍底床、素材缓推这类持续运动的时长 = 段落时长，
  **写速率不写固定秒数**（例如缩放 0.5%/s、横移 2.8px/s）。
  文字退场那 0.4s 底床与素材一起收 —— 不许出现「字没了、画面还在空转」的尾巴。

时长经验：**节奏宁慢勿快**，第一版几乎总是偏快。开场主体动作（聚焦→悬浮→归位）
至少 3 秒；模拟真实交互（打字、筛选、点击）按真人操作速度走，观众要能跟着做一遍。

## 3. 让位（三种方式，按「这元素还回不回来」选）

| 情况 | 做法 |
| --- | --- |
| 本拍讲完不再回指 | **真退场**：0.15–0.5s 出场后从画面消失 |
| 马上还要回指 / 对照 | **降权留守**：缩小 0.92 + 上移 + 亮度 −66% + 3px 模糊，原位保留 |
| 长镜头段 | 相机离开即让位 |

**降权留守仍然占版面**——排版预算（同屏 ≤3 组、空象限）必须把它计入。
浅底上降权糊影依旧醒目，同屏留守别超过 1 组。

让位时机：新主体入场前 6 帧开始旧主体的降权。**一个节拍只有一个主角，说完就让位。**

## 4. 转场

**硬规则：每个段落边界都必须有明确的转场处置，禁止裸切。**

转场方式（择一，并写明用了哪种）：运动承接（A 的运动延续为 B 的运动方向）/
形状擦除 / 图形接力 / 长镜头连续运镜 / 刻意的硬切（须是设计过的，不是忘记处置）。

转场处前后段落的**运动方向要连续**，否则观感是「跳了一下」。

## 5. 排版预算（管「放多少」）

> 「放哪、多大、怎么对齐」在 `references/layout.md`，两份一起核。

被判「凌乱」的段落通常不是单个动效错了，而是**排版没有预算**——
元素只进不出、四角加中带全占、同一信息写两遍。逐段核：

1. **按语义段落切分**，禁止机械地「一句一个画面」；每段只许一个主要任务
   （钩子 / 定义 / 数据 / 流程 / 对比 / 结论 / 号召 之一）。
2. **转折句归下一段**：「但这次不是 X」这类转折 / 否定 / 设问是下一段的**第一拍**——
   切点提前到转折句起点，旧段先清场，新动效上干净的舞台。
3. **同屏预算**：任一时刻主体组 ≤3（字幕与常驻件不计；**降权留守的元素计入**）；
   第 4 组进场前必须有一组真退场。
4. **留白锚**：每段全程保留至少一个空象限；四角加中带全占的环形满盘 = 视线无路径，判凌乱。
5. **主角造型一屏一个**：多个数字 / 大字同屏时只有一个享受大字号或色块待遇，
   其余降为行内注——三个数字三种造型互相抢戏读作凌乱。
6. **画面文字不照抄字幕**：画面文字是 ≤12 字的提炼，不是口播誊写；
   与字幕整句重复 = 同一信息双份同屏。
7. **布局事件预算**：人物形态切换 / 构图重排这类布局级变化**每分钟 2–4 次**，
   「切换是标点不是节拍器」；合法触发只有新论点 / 图表替换 / 前后对比 / 结论，
   纯时间流逝与每条字幕都不算。
8. **错峰三段序**：旧面板**完全退场** → 人物换位或新主体入场 → 新面板才淡入，
   三者不得交叠。
9. **版式轮换**（管段与段之间）：「每段都对」不等于「整片好看」——
   11 段里 8 段用同一种版式，就是每段都过了闸的成片。
   - 同一类表现手法**不得连用 3 段**（连 2 段可以，第 3 段必须换式），全片占比 ≤1/3；
   - **人物形态 × 方位**与**素材容器**两个变量，连续 3 段至少换其一，两者都不变即缺陷；
   - 同一条 B-roll 素材不进相邻两段、全片 ≤2 段；
   - **轮换是换构图，不是加运动**——每一式内部仍只有相机极缓推拉。

## 6. 验收口径（成片逐条核）

1. 英雄帧 4–6 层活跃；任意静息帧**相机在动**。
2. **任意 0.8s 不允许全静止** —— 由 `scripts/qaGate.mjs` 自动检测。
   素材本身要求静止的段落（标志落定、定格）会撞这一关，
   **处置不是豁免，是让相机替它动**（相机极缓续推，素材一个像素不动）。
3. **每个段落边界都有明确转场处置**，且前后运动方向连续。
4. 一个节拍只有一个主角；说完必须让位，不许堆积满屏。
5. 排版预算逐段核：同屏主体组 ≤3、空象限在、主角造型唯一、
   画面文字与字幕无整句重复。
6. **字与画同起同收**：每段最后一个退场结束 = 段尾；
   段尾之前不许出现「文字已退、底床独自空转 >0.4s」。
7. **可读性终检**：成片**缩到 390px 宽**复看一遍，每行都要能读 ——
   桌面全屏预览不是验收标准。排不下时先删次要文案，不缩字号、不留孤字行。

## 7. 工程铁律（从返工中提炼）

- **绝对秒只许出现在具名参数上**，不要写进表达式实参 ——
  批量改时间时，散在算式里的字面量是最容易漏改的一批。
- **时间以绝对秒为准**，只在需要帧号时换算一次；不要提前取整。
- **参考素材先逐帧拆解成手法清单，再逐段判断适配性**，不全局套用：
  图片参考描述的是「某一类镜头」的感觉，不是全片风格令。
- **一种动画手法全片只当一次主角**；重复镜头与重复信息一律删。
- **指代含糊的反馈先确认对象**；改错了整段回退重做，不在错误版本上打补丁。
