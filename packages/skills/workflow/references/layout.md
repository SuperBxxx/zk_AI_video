# 排版规范（放哪、多大、怎么对齐）

`references/cinematography.md` 的排版预算管**放多少**（同屏 ≤3 组、空象限、主角唯一）；
本文管**放哪、多大、怎么对齐**。两份一起核。

> **落地形态说明**：我们的画面由节点产出（生成模型的画面、FFmpeg 滤镜合成的图层）。
> 所以本文给的是**画幅内的几何规范**——写生成提示词、摆字幕与花字、
> 用 FFmpeg 叠图时按它定位；它不是某个组件库的 API 文档。
> 所有数值按 1920×1080 给出；竖屏 1080×1920 的差异只在安全区与字幕带。

## 1. 安全区与字幕带

- **安全边 96**（四边）、**标题边 160**；**字幕带保护区 y ≥ 900**，只放字幕。
- 元素离画幅边 ≥ 96；**< 64 即判贴边**。
- 竖屏（1080×1920）：常驻件必须放**左下** —— 右缘是平台点赞栏的位置。

## 2. 网格与吸附

- **12 栏栅格**：内容宽 1728（1920 − 2×96），gutter 32，栏宽 114.67；
  栏线 `x_i = 96 + i × 146.67`（i = 0…12）。
- 元素左右边缘**吸附栏线**（容差 ±4px）。
- 常用跨度：全宽 12 / 主列 8 / 侧列 4 / 双列 6+6 / 三列 4+4+4 / 一主两辅 7+5。
- **竖向锚**：中线 y=540、三分线 y=360 / 720。
  单主体落中线；**有字幕时主体组底边 ≤ 860**。

## 3. 间距令牌与层级

- 令牌（8 的倍数）：**8 / 16 / 24 / 32 / 48 / 64 / 96 / 160**。不用令牌外的随手数。
- **层级铁律：外边距 ≥ 组间距 ≥ 组内间距**（96 ≥ 48~64 ≥ 16~32）。
  反例：左列标题与右列列表中间空 400px、列表右边离画幅 40px ——
  **间距倒挂**（内大外小），读作「两坨东西各自贴边」。
  修法是**整组收进栏格再居中**，不是改某个 margin。
- 组内相邻元素等距，≥ 24；标题与其下内容 ≥ 32；章节级标题与内容 ≥ 96。

## 4. 对齐

- 同组元素**左边缘对齐同一栏线**（或右对齐同一栏线），不许各自为政。
- **以字形边缘为准，不以容器盒为准**：色块 / 胶囊 / 图标与文字同组时，
  色块左边 = 标题首字左边；有内间距的元素把间距**反向补偿**（负 margin）。
- **基线对齐**：同一行的图标 / 数字 / 文字对齐基线；数字用等宽数字
  （`tabular-nums` 或等价做法），避免滚动时宽度跳动。
- **标注类几何由目标包围盒实测反推**（框 / 圈 / 下划线 / 箭头 / 取景框）：
  四边留白 16~24 等距，**不目测**；实现后抽定妆帧核对，偏差 **> 8px 返工**。
  反例：对角角框的左上角离首字 80px、右下角压到末字下方 —— 框没套住字。

## 5. 居中与配重

- **无人物在场**：主体组的**包围盒**水平居中（不是第一个元素居中）；
  纵向落中线或上三分线（给字幕带留空）。
- **有人物在场**：主体组放人物对侧，组包围盒中心落在该侧半幅中心
  （x = 480 或 1440），**文字及其底板全时刻不入人脸安全区** ——
  人脸安全区优先级高于「居中」。
- **双元素组**：宽度比 1:1 或 2:1（黄金比 1.618:1 亦可），
  间距取组内令牌 32~64，两元素顶边对齐，整组包围盒居中。
- **偏一边的判定**：组包围盒中心与目标中心偏差 **> 48px**。

## 6. 字阶与可读

| 档 | 字号 | 用途 |
| --- | --- | --- |
| hero | 96~120 | 单句独占一段、金句、章节名 |
| title | 64~72 | 段落标题 |
| subtitle | 44 | 底部跟读字幕（素排） |
| body | 40~44 | 列表条目、标签、卡内正文 |
| caption | 28~32 | 图注、辅助说明 |
| micro | 22~24 | 来源行、时间戳 |

- **最小可读 28**（成片缩到 390px 宽复看仍能读）；
  **列表条目 / 标签 / 要点 ≥ 40** —— 低于条目档等于没有。
- **底部字幕 ≥ 56px**（帧高的 5.2%；1080 下推荐 60px）。
- **标题字数 → 字号档**（一行 ≤ 14 个汉字，超了拆行不缩字）：
  ≤6 字 120 / 7~10 字 96 / 两行各 ≤8 字 84 / 两行有 9~12 字 72 / 三行 64。
- 字重两档；hero 用 600、title 用 700，**不加粗到 800 以上**（越大越轻）。
- 同屏 hero : body **≥ 2:1**，没有对比就没有层级。

## 7. 碰撞与溢出

- **任意两个元素的包围盒不得相交**。例外只有三类刻意叠层：
  标注压在素材上、字幕带、标签压在实拍画面上。
- **文字块列宽 ≥ 最长行实测宽 + 2×padding**，文字不越出自己的列。
  放不下的处理顺序：**先删字 → 再拆行 → 最后才缩字号**。
- 字幕带（y ≥ 900）内不放任何主体；主体底边 ≤ 860。
- 溢出分档：1~40px 微调；40~90 局部收紧；90~160 压标题 / 正文；
  **> 160 换版式或删内容**，不用 margin 硬救。

## 8. 色彩与底板

- **强调色只有一个**。
- **列表 / 标签底板用淡色系区分**：同组 3~6 项各配一个淡色底，同组不重复，
  文字保持墨色：蓝 `#E8F0FF` / 粉 `#FFE9F0` / 紫 `#EFE9FF` / 青 `#E6F7F2` /
  黄 `#FFF4DC` / 灰 `#F2F2F5`。
  反例：三枚白底同色标签，读作三个一样的空框。
- **章节标题按章轮换配色**：深底四套 藏蓝 `#0f1e3d` / 墨绿 `#10261f` /
  酒红 `#2b1218` / 炭黑 `#16161a`，或浅底四套；编号与章节名用对比色随底切换。
  **禁止每章同一个色**。
- 深浅底交替分段。

## 9. 一致性

- 同组元素同一造型类：白边卡 / 描边卡 / 实色卡 **三选一不混**；
  同组图片统一比例与高度（裁切统一，不各自缩放）。
- 圆角三档、投影一个；同组标签同高同内间距。

## 10. 校验九项（定稿时逐项过）

实现后抽定妆帧，逐项核：

1. **贴边**：离画幅边 < 64。
2. **间距倒挂**：组内间距 > 外边距。
3. **左边缘未吸附栏线 / 未按字形对齐**。
4. **无人物时组包围盒未居中**（偏差 > 48）。
5. **标注几何未套住目标**（> 8px）。
6. **字号低于档**（正文 28 / 条目 40 / 独句 hero）。
7. **包围盒相交**。
8. **同组底板同色 / 章节同一色**。
9. **缩到 390px 宽不可读**。

任一项失败按 P1 记（缺陷分级见 `references/` 的评审规范），修完再渲染该段。
