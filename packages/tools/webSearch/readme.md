# 联网搜索

搜索公开网页，为 Agent 提供标题、来源链接和摘要。

默认是**自动**模式：按 DeepSeek → Tavily → DuckDuckGo 的顺序挑一个能用的，并把实际用了哪个报出来。

> **国内网络要注意**：实测 DuckDuckGo 两个域名（html / lite）都连不上（6 秒超时），
> 而 DeepSeek 官方接口与 Tavily 都可达。所以想真正搜到东西，请看下面的「配置」一节，
> 填一个 DeepSeek 或 Tavily 的 Key。

## 使用方式

在对话中直接提出检索任务，例如：“搜索最近的 AI 视频制作资料，列出来源和要点。”
搜索结果适合发现资料；需要核对完整正文时，可配合“读取网页”工具。

## 配置

在「设置 → 工具配置」里找到「联网搜索」，点击「配置」。

- **搜索服务**：
  - **自动（推荐）** —— 按 DeepSeek → Tavily → DuckDuckGo 逐个尝试，用上第一个能用的
  - **DeepSeek** —— 国内最稳（实测接口 113ms 可达），需填官方 DeepSeek API Key
  - **Tavily** —— 需填 Tavily API Key
  - **DuckDuckGo** —— 免 Key，但**国内通常不可达**，除非配了代理
- **DeepSeek API Key**：选 DeepSeek 或自动模式时填（自动模式没填就跳过它）。必须是官方密钥，
  其他供应商或中转平台的密钥不能替代。
- **Tavily API Key**：同上。
- **代理（可选）**：例如 `http://127.0.0.1:7892`。留空即直连。
  **填了但探测不通的代理会被自动忽略** —— 死代理会让所有请求立刻失败，比不设代理更糟，
  所以这里会先确认那个端口真的有服务在听。
- **最多返回结果**：默认 8 条，可设为 1–20 条。
- **超时（毫秒）**：默认 30000，可设为 1000–60000。

## 失败时

报错会列出**每个被尝试的服务各自的失败原因**，并把「没配置的」与「试了但失败的」分开说 ——
免得去查错方向。例如：

```
联网搜索失败：
  · duckduckgo：连接超时（6000ms 内没有响应）…
其中 deepseek、tavily 没有配置，未被尝试。
```

「连接超时」在国内的真实含义通常是**该服务的域名不可达**，而不是服务本身故障。

## 说明

结果包含来源网址，Agent 可以据此引用资料；**搜索摘要不等于已经读取完整网页**。
