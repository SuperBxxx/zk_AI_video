feat(音色): 供应商契约加 createVoice，百炼实现 + 服务端接口（P4 服务端链路）

需求来源：D2/D3/D4 —— 声音克隆与声音设计都要做，样本支持上传与录制，
克隆出的音色以 json 存进素材库「声音」文件夹。

改动
1. packages/providers/types.d.ts
   - ProviderDefinition 增加可选 createVoice?（与 generateImage/Video/Audio 并列），
     未实现的供应商保持缺省，调用方据此判断能力。
   - 新增 CreateVoiceRequest（model / name / sample / description / targetModel / other）
     与 VoiceResult（voice / label?）。
   - sample 用 MediaInput 而非工作区路径：ProviderTools 没有读取工作区文件的能力
     （只有 fetch / errorMessage / hash / image / audio.convert / ffmpeg），
     所以样本字节必须由调用方准备，前端读素材后转 base64 提交。
   - types.d.ts 无 import/export，是全局脚本作用域，故这些类型对 providers 与
     经 `@toonflow/providers` 引入的 server 均可见（generation.ts 已在用 MediaAsset 佐证）。

2. packages/providers/src/media/bailian.ts 实现 createVoice
   - 只走 Qwen-TTS 的声音复刻（model: "qwen-voice-enrollment"，input.action: "create"），
     样本走 input.audio.data（Base64 Data URL）。
     原因：Qwen-Audio-TTS / CosyVoice 的 voice-enrollment 要求样本是「公网可访问 URL」，
     而本产品样本来自本地上传与现场录音，没有公网托管，那条路不可行。
   - 传 input.text（而非 sample）时即声音设计（用文字描述造音色），不消耗样本。
   - preferred_name 按平台规则清洗为至多 16 位字母数字下划线；target_model 可选传入。
   - 新增 dataUrl() 把 MediaInput 转成 Data URL；新增 voicePath 常量
     /services/audio/tts/customization。

3. apps/server/src/utils/media/generation.ts
   - 把 generateMedia 里内联的「解析供应商 + 校验模型 + 校验 API Key」抽成
     resolveMediaProvider(providerId, modelId, modelType, signal?, cwd?)，
     generateMedia 改为调用它。避免新增音色接口时复制一份导致两处同步维护。
   - 新增 createMediaVoice()：复用 resolveMediaProvider，校验供应商是否实现
     createVoice，再调用并校验返回了音色标识。
   - 已核对重构后没有产生未使用的 import（各依赖仍在文件内被引用）。

4. apps/server/src/routes/ai/voices/create.ts（新增）
   - POST /api/ai/voices/create，参数：providerId / modelId / name /
     sample?(base64+audio mime) / description? / targetModel?
   - 沿用既有生成路由的资源清理写法（close / aborted / socket close 三处 abort 监听）。
   - 已执行 bun run routes，router.ts 自动登记为 /api/ai/voices/create（route24）。

验证
- apps/server typecheck：0 错误；构建退出码 0
- apps/web typecheck 保持既有基线 7 个；前端生产构建退出码 0
- 运行时载入 packages/providers 打印能力矩阵：
  apiMart = generateImage, generateVideo, generateAudio
  bailian = generateAudio, createVoice
  meta    = generateVideo
  即 createVoice 仅百炼具备，与「APIMart 文档只提 TTS、未提克隆」一致
